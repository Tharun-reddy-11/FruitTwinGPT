# Fruit Twin GPT frontend

This is the React + Vite user interface for Fruit Twin GPT.

```powershell
Set-Location D:\Projects\FruitTwinGPT\frontend
npm install
npm run dev
```

Create a production bundle with `npm run build`. The application currently presents a clearly labelled demonstration workflow; it must not be represented as a validated fruit-quality prediction system until a linked, documented research dataset and trained model are available.
