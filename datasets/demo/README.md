# Demonstration fixtures only

The CSV files in this directory are small, manually constructed test fixtures. They exist solely to exercise imports, API contracts, dashboards, and the Digital Twin user interface.

They are **not** Kaggle data, field measurements, real-time feeds, or scientific evidence. Do not use them for training, model selection, evaluation, or reported performance. Genuine research data must be stored separately with source, license, units, collection method, feature definitions, image linkage, plant/plot identity, observation timestamps, and later measured harvest outcomes documented.
